# 🎮 Neon Runner

**Неоновый 2D экшен-платформер** на чистом HTML5 Canvas + JavaScript (без зависимостей и сборщиков).

![genre](https://img.shields.io/badge/genre-action%20platformer-neonpink)
![tech](https://img.shields.io/badge/tech-HTML5%20Canvas%20%2B%20WebAudio-cyan)
![deps](https://img.shields.io/badge/dependencies-zero-brightgreen)

---

## ✨ Особенности

- 🔊 **Процедурный звук** — ~20 эффектов (выстрелы, прыжки, удары, взрывы) и генерируемая synthwave-музыка прямо в браузере через Web Audio API. Никаких mp3-файлов!
- ⏳ **Экран загрузки** с анимированным прогресс-баром
- 🛒 **10 улучшений** — урон, скорострельность, двойной прыжок, регенерация, магнит монет и др. Покупаются за игровые монеты, прогресс сохраняется в `localStorage`
- 🗺️ **6 уровней** с нарастающей сложностью, боссами с паттернами атак и порталом победы
- 💾 **Автосохранение** монет, улучшений и открытых уровней между сессиями
- 🌆 Параллакс-фон, частицы, тряска экрана, i-frames, камера следит за игроком

## 🎮 Управление

| Действие | Клавиши |
|---|---|
| Движение | `A` / `D` или `←` / `→` |
| Прыжок (двойной — с апгрейдом) | `W` / `↑` / `Space` |
| Стрельба | `X` / `J` |
| Пауза | `P` / `Esc` |

> Звук включается по первому клику (требование автоплей-политики браузеров). Кнопка mute — в меню и HUD.

## 🚀 Локальный запуск

Просто откройте `index.html` в браузере, либо поднимите локальный сервер:

```bash
git clone https://github.com/dimonlimon949/neon-runner.git
cd neon-runner
python3 -m http.server 8000
# → http://localhost:8000
```

После включения GitHub Pages игра будет доступна по ссылке из About репозитория.

## 🕹️ Геймплей-цикл

1. Уничтожайте врагов (жуки, дроны, турели) и боссов ради **монет и опыта**
2. Покупайте улучшения в **магазине между уровнями**
3. Открывайте новые уровни, дойдите до финального босса и победы 🏆

## 📂 Структура проекта

```
neon-runner/
├── index.html        # UI: экран загрузки, меню, HUD, модалки
├── style.css         # Неоновый стиль, анимации
└── js/
    ├── audio.js      # Процедурный SFX + музыка (WebAudio)
    ├── upgrades.js   # Магазин улучшений + localStorage
    ├── levels.js     # 6 уровней, генерация платформ и врагов
    ├── enemies.js    # 4 типа врагов + боссы с паттернами
    ├── player.js     # Физика, стрельба, прокачка
    └── game.js       # Движок: камера, частицы, коллизии, цикл
```
